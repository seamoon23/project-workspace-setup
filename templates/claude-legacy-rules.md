## 절대 규칙 (항상 적용)

1. **운영 하한** 문법·API·라이브러리 판단 기준은 운영({PROD_JDK}/{PROD_WAS})이다. 개발 PC에서 돌아도 운영에서 안 돌면 실패.
2. **버전 동결** 의존성 신규 추가·버전 업그레이드·드라이버 교체 금지. 필요하면 기존 라이브러리로 직접 구현하거나 사용자에게 질문.
3. **폐쇄망 자급자족** 외부 CDN·원격 폰트·런타임 외부 API 호출 금지. 빌드는 오프라인 모드({BUILD_CMD}, mvn -o)만 — 원격 저장소 접근 실패를 미러·저장소 설정 추가로 "고치지" 말 것. 모든 리소스는 WAR 안에 로컬 포함.
4. **JDK {PROD_JDK} 문법만** 상위 문법·API 금지: {FORBIDDEN_SYNTAX 예: 1.6이면 다이아몬드·try-with-resources·String switch까지, 1.8이면 var·List.of()·Stream.toList()}. 운영 JDK 불명 시 가장 낮은 호환으로 작성 후 사용자 확인.
5. **{PROD_DB} 문법만** {DB_ALLOWED 예: ROWNUM·SYSDATE·NVL·DUAL} 사용. 타 DB 함수 {DB_FORBIDDEN 예: NOW()·IFNULL·LIMIT} 금지.
6. **UTF-8·탭** 전 파일 UTF-8 고정, JSP 상단 charset 지시문 유지, 탭 들여쓰기 유지. 스페이스 재포맷·한글 깨뜨리는 변경 금지.
7. **자격증명 평문 금지** {SECRET_FILES 예: context-datasource.xml·globals.properties}의 비밀번호·키를 코드·로그·문서·PR에 노출 금지. 기존 평문 발견 시 수정 말고 보고만.
8. **기존 패턴 복제** {REFERENCE_MODULE 예: symptom} 모듈을 레퍼런스로 구조·네이밍·예외처리를 그대로 모방. 새 패턴 발명·요청 없는 "더 나은 방법" 금지.
9. **최소 범위** 요청 밖 리팩터링·import 정리·코드 재배열·일괄 재포맷 금지.
10. **보안 우회 금지** 기존 필터·인터셉터({SECURITY_CHAIN 예: XSS 필터·CSRF·세션체크})를 그대로 통과시킬 것. SQL 파라미터는 #{} 바인딩만, ${} 금지.
11. **ASCII 경로** 경로·브랜치·작업 폴더명은 영문 소문자+숫자+하이픈만. 한글·공백·특수문자 금지.
12. **운영 WAS 로컬 기동 금지** 로컬 확인은 {DEV_WAS}로만. {PROD_WAS} 고유 동작(JNDI·JTA 등)은 운영 배포 후 별도 확인.
13. **검증 후 완료** 변경 후 {BUILD_CMD} 빌드 검증 필수. 검증 실패·미수행 상태로 "완료" 보고 금지.
